## NeoGate v0.4.0

NeoGate v0.4.0 expands project-level model governance, improves relay observability, and polishes admin and user usage workflows for production private deployments.

### Highlights

- Added project model configuration with database-backed model policies, project-scoped model controls, app integration support, and refreshed project model design notes.
- Added smart project model routing and automatic model routing improvements so projects can resolve model access and upstream routing with stronger server-side controls.
- Improved admin model configuration with settings APIs and console controls for managing model behavior from the admin interface.
- Added usage routing details across backend billing records, admin usage tables, and user usage views so requests expose clearer route, provider, channel, and error context.
- Added streaming relay diagnostics and updated streaming proxy timeouts to make long-running streaming requests easier to inspect and operate behind Nginx.
- Added configurable site branding and refined public, admin, login, setup, and layout surfaces so self-hosted deployments can present customized product identity.
- Improved admin project, upstream, provider, channel, user, payment, and usage interfaces with clearer dialogs, aligned table actions, refined provider selection, and richer usage display.
- Unified user concurrency limits and improved backend relay, provider, policy, billing, payment, usage recording, and daily usage internals for better consistency.

### Upgrade Notes

- This release includes a database migration for project model configuration: `backend/migrations/0004_project_models.sql`. Run migrations before starting the upgraded services.
- Review project model settings after upgrading, especially deployments that rely on project-specific model allowlists, app integrations, or automatic routing behavior.
- If NeoGate is deployed behind Nginx or another proxy, apply the updated proxy timeout examples so streaming relay requests are not terminated too early.
