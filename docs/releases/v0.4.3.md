## NeoGate v0.4.3

NeoGate v0.4.3 is a patch release focused on admin navigation polish, billing-mode UX consistency, and version metadata alignment across backend, scheduler, and frontend builds.

### Highlights

- Hid the admin cost attribution menu in paid service mode so billing-mode deployments keep the left navigation focused on paid-user operations, pricing, recharge, and usage records.
- Added a direct-route guard for `/admin/cost-attribution` in paid service mode, redirecting admins to the consumption overview instead of exposing a hidden internal-mode page.
- Kept internal service mode unchanged: administrators can still access cost attribution from the usage navigation and drill into project, member, key, and model cost dimensions.
- Updated backend, scheduler, and frontend version metadata to `0.4.3` so admin version checks, build artifacts, and package manifests report the same release.

### Upgrade Notes

- No new database migration is included in this release. Deployments upgrading from v0.4.2 can reuse the existing schema.
- Rebuild backend, scheduler, and frontend artifacts together so runtime version metadata and the admin navigation behavior stay aligned.
- Paid-mode deployments should verify the admin sidebar after upgrade: "Cost attribution" should no longer appear, and direct visits to `/admin/cost-attribution` should redirect to `/admin/statistics`.
- Internal-mode deployments should verify that cost attribution remains visible and behaves as before.
