## NeoGate v0.3.2

NeoGate v0.3.2 is a patch release focused on operational recovery, payment reliability, admin observability, and China deployment ergonomics.

### Highlights

- Added a server-side admin password reset command (`neogate admin reset-password`) so locked-out administrators can recover access without database access.
- Improved admin usage and upstream service tables: the usage table now shows the full relay path with the current leg highlighted, a hover popover with structured trace details, a username-first user column, and wrapped error cells; the upstream table gained an ID column and refined layout.
- Added a public payment return page for ZPay and now derive the ZPay notify URL from the public base URL instead of requiring manual configuration.
- Improved payment diagnostics by logging the resolved notify URL.
- Sped up China Docker Compose builds and updated the CN compose and Nginx proxy configuration.
- Restored automatic Cargo build parallelism and cleaned up placeholder Cargo artifacts in the backend Docker image.

### Upgrade Notes

- If you previously configured a ZPay notify URL manually, it is now derived from `PUBLIC_BASE_URL`; verify your payment callbacks after upgrading.
- To reset a forgotten admin password, run `neogate admin reset-password --username <admin>` (or pipe a password via `--password-stdin`) inside the backend container.
- No database migration is required for this patch release.
