## NeoGate v0.3.0

NeoGate v0.3.0 adds app integrations, stronger routing and billing controls, account security improvements, and clearer deployment examples.

### Highlights

- Added Apps for publishing model-backed workflows through Enterprise WeChat, Feishu, DingTalk, webhooks, and embeddable widgets.
- Added an admin Apps console for app creation, endpoint configuration, detail views, and run metadata.
- Added upstream affinity routing and failover tracing for more predictable multi-channel routing.
- Added multi-meter billing for token and image workloads, with improved pricing and usage aggregation.
- Hardened account security with Argon2id password hashing, signed tokens, password reset emails, and stronger admin session validation.
- Added admin version checking against GitHub Releases.
- Clarified Docker and Nginx deployment examples for Docker Compose and source-build deployments.
