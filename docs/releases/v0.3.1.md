## NeoGate v0.3.1

NeoGate v0.3.1 is a patch release focused on provider compatibility, protocol bridging correctness, billing reliability, and admin console polish.

### Highlights

- Added provider adapter configuration and diagnostics to make upstream-specific behavior easier to tune and inspect.
- Added Sub2API provider support.
- Improved JDCloud prompt cache compatibility and applied provider adapters to Anthropic chat fallback paths.
- Improved OpenAI Responses capability handling with runtime per-endpoint and per-model downgrade behavior.
- Fixed Chat Completions to Responses bridging so tool calls after text content are preserved.
- Improved Anthropic fallback, Codex chat fallback compatibility, and bridged Responses behavior.
- Improved billing settlement reliability, task polling, and graceful billing shutdown.
- Normalized price keys and model casing for more consistent billing and usage accounting.
- Improved upstream channel model configuration and Claude Code cache affinity.
- Refined first-run setup, admin site settings, account recharge setup, and default project provisioning for paid users.
- Polished admin list scrolling and project member dialog scrolling.
- Limited Rust build parallelism in Docker to reduce build-time resource pressure.

### Upgrade Notes

- Review provider adapter settings after upgrading if you rely on provider-specific compatibility behavior.
- Recheck pricing records for custom models because price keys and model casing are now normalized more consistently.
- No database migration is required for this patch release.
