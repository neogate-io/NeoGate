# Security Policy

NeoGate manages project API keys, upstream provider credentials, billing records, and administrative access. Please report security issues privately.

## Reporting a Vulnerability

Do not open a public issue for security-sensitive reports.

Please email the maintainer or use GitHub's private vulnerability reporting if it is enabled for the repository. Include:

- Affected version or commit
- Steps to reproduce
- Impact and expected behavior
- Any suggested mitigation

## Sensitive Data

Never share real upstream API keys, database credentials, session secrets, payment secrets, or production logs containing user data in public issues or pull requests.
