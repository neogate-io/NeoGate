NeoGate - 私有化 Rust 大模型 API 网关

NeoGate 将 OpenAI 兼容接口、Anthropic 兼容接口、模型路由、上游凭证管理、 用量统计和计费能力收拢到一个可私有化部署的统一网关中。

核心能力

团队共享模型访问之前，该有的控制面都在这里。

NeoGate 适合需要统一管理上游模型账号、项目 API Key、访问权限、用量和成本的组织， 避免把供应商密钥分散到每个服务和团队里。

统一模型入口

用一个网关管理多个上游供应商、协议、端点和凭证。

项目 API Key

为团队、客户、服务和自动化任务发放相互隔离的调用密钥。

模型路由

按模型、供应商、优先级、权重、凭证状态和通道健康度选择上游。

用量记录

按用户、项目、API Key、模型、供应商和上游通道追踪请求。

计费模式

既可作为内部网关，也可开启余额、充值、价格和面向客户的付费访问。

私有化部署

从 Docker Compose 单节点启动，后续按流量需求切换到集群部署。

架构

从项目 Key 到上游凭证，只有一条受控路径。

请求通过 OpenAI 兼容或 Anthropic 兼容接口进入网关，经过项目策略检查， 选择上游通道并记录用量，用于排障、成本归集或计费。

1认证项目 API Key
2检查策略、服务模式和余额
3选择供应商通道和上游凭证
4转发响应并记录用量

快速部署

使用 Docker Compose 启动单节点网关。

git clone https://github.com/neogate-io/NeoGate.git cd NeoGate docker compose up -d --build

启动后打开部署地址，通过首次运行向导完成管理员账号、服务模式、初始上游、价格、 SMTP 和支付配置。
