## NeoGate v0.4.2

NeoGate v0.4.2 is a patch release focused on admin cost attribution, consumption analytics, relay compatibility, installation reliability, and CNY-mode provider pricing.

### Highlights

- Added a dedicated admin cost attribution view with project, user, and model dimensions, multi-level drilldowns, CSV export, and routing shortcuts from analytics tables.
- Expanded admin consumption analytics with aligned filters, richer statistics APIs, project/member/model breakdowns, latency and throughput metrics, and clearer table presentation.
- Improved relay compatibility for Responses-style traffic, including better streaming SSE error diagnostics, learning unsupported Responses models from streaming failures, and treating token-limit stops as completed bridge responses.
- Protected routing availability during channel probes and soft failures so diagnostic or upstream soft-fail signals do not unnecessarily cool down healthy channels or disable usable models.
- Improved JDCloud compatibility by fixing streaming `Accept` handling and recognizing account-login failures as authentication failures with clearer 403 diagnostics.
- Fixed stale credit allocation handling so old pending allocations no longer cause billing records to fail permanently.
- Added FX-converted OpenAI and Anthropic reference prices for CNY billing mode, refreshed model pricing data, and included a Models.dev pricing fetch tool.
- Hardened install and setup flows, including Windows Node.js repair, Windows zip-extract bin path detection, China npm/Node.js mirror support, existing-config startup behavior, Codex desktop base URL preservation, and setup branding polish.
- Cleaned up release engineering by resolving relay clippy warnings that blocked CI and extending Docker image workflow coverage.

### Upgrade Notes

- No new database migration is included in this release. Deployments upgrading from v0.4.1 can reuse the existing schema.
- Rebuild backend, scheduler, and frontend artifacts together so admin analytics APIs, cost attribution UI, and version metadata stay aligned.
- If you operate in CNY billing mode or publish provider reference prices, verify the upstream CNY reference-price source before exposing custom pricing tables.
- If you use the generated installer scripts, regenerate or redistribute the v0.4.2 scripts so Windows Node.js repair, China mirror, existing-config, and Codex desktop URL fixes are included.
- Review relay monitoring after upgrade: probe soft failures and Responses streaming errors are now classified more precisely, which can change cooldown and fallback behavior compared with v0.4.1.
