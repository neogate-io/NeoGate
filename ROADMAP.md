# NeoGate Roadmap

This roadmap is a directional guide, not a fixed release contract.

## Near Term

- Improve provider compatibility documentation.
- Add more deployment examples for common reverse proxy and cloud environments.
- Expand admin diagnostics for channels, endpoints, and credentials.
- Improve usage analytics and billing visibility.
- Add more focused smoke tests for OpenAI-compatible and Anthropic-compatible flows.

## Later

- More provider templates and pricing presets.
- Stronger observability around relay latency, retries, and failover.
- Fine-grained project policy controls.
- More enterprise deployment guidance for clustered mode.
