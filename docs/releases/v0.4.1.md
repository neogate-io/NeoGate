## NeoGate v0.4.1

NeoGate v0.4.1 is a patch release focused on billing currency flexibility, provider price references, admin settings polish, relay compatibility, and release engineering reliability.

### Highlights

- Added configurable billing currency support for USD and CNY across backend billing, usage summaries, recharge flows, admin statistics, user overview, and frontend formatting.
- Expanded provider reference pricing with generated model price data and fetch tools for DeepSeek, Qwen, Kimi, MiniMax, Zhipu, and Volcengine Ark, with DeepSeek defaulting to CNY reference pricing.
- Improved admin pricing workflows with clearer reference-price data sources, richer price display modes, refined channel price dialogs, and a fix for Zhipu flagship model reference prices being multiplied incorrectly.
- Added a dedicated admin site settings page and moved site configuration and version checking into the settings area.
- Improved first-run setup and install scripts, including clearer auto-configuration behavior and public documentation links.
- Fixed JDCloud relay compatibility for Responses-style requests and cleaned up project model options and redundant provider fields.
- Improved upstream failure diagnostics and relay streaming behavior, including treating `response.incomplete` as a terminal SSE event.
- Refined admin statistics, project, channel, app, user, recharge, and usage interfaces for clearer billing amounts, routing context, and operational copy.
- Added CI workflow, pre-commit formatting hooks, and contributor/development documentation to make release checks easier to reproduce.

### Upgrade Notes

- This release includes provider cleanup database migration `backend/migrations/0005_provider_cleanup.sql`. Run migrations before starting upgraded services.
- Review billing currency settings after upgrading. Deployments that previously assumed USD-only billing should confirm the configured currency, recharge amounts, and displayed reference prices.
- If you use provider reference prices operationally, verify the configured upstream reference-price source before publishing custom pricing tables.
- Rebuild backend, scheduler, and frontend images together so version metadata, admin settings, and billing currency display stay aligned.
