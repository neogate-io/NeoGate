## NeoGate v0.3.3

NeoGate v0.3.3 is a patch release focused on usage analytics, faster Docker installation, payment order reliability, and first-run documentation.

### Highlights

- Added an admin usage statistics dashboard with summary metrics, daily trends, provider distribution, top users, top models, paginated breakdown tables, filtering, sorting, and CSV export.
- Improved user usage details with clearer token, latency, billing, route, and error sections, plus date filtering and CSV export from the user console.
- Added prebuilt Docker images for the backend and web frontend. The default `docker-compose.yml` now pulls images from GHCR, while source builds move to `docker-compose.build.yml`.
- Kept the Mainland China Docker Compose path as a source-build profile with mirror configuration in `docker-compose.cn.yml`.
- Improved ZPay recharge handling by adding numeric payment order numbers, passing a payment return URL, accepting GET notifications, and showing a clearer public payment success page.
- Added database indexes for usage statistics queries to improve common admin reporting filters.
- Updated installation and auto-configuration docs, including the public docs page, README screenshots, and new 10-minute quickstart guides in English and Chinese.
