## NeoGate v0.4.5

NeoGate v0.4.5 is a patch release focused on relay reliability, security hardening, billing correctness, provider compatibility, and admin UX polish.

### Highlights

- Refactored the streaming relay internals into smaller modules, reducing duplication and making request/response handling easier to maintain.
- Improved relay reliability and billing correctness with safer hold release paths, better output-token reservation and settlement, byte-based disconnect billing, and fixes for route-cache reload races.
- Hardened security and isolation by tightening SSRF protections, isolating worker panics, and closing several async-task and upstream hold-leak edge cases.
- Expanded provider compatibility across OpenAI-compatible, Anthropic, Alibaba realtime ASR, HaxiCloud/GlobalAI OPC, and NewAPI-related routing paths.
- Improved audio and video workflows, including audio transcription and streaming reliability, video reference alignment, and richer video adapter support.
- Polished the admin experience and docs with upstream form and feedback style updates, interface documentation restructuring, and broader release documentation cleanup.
- Refreshed pricing, usage, and relay metrics logic, including provider label fixes, usage-estimation improvements, prompt-cache accounting, and CNY pricing source updates.
- Updated backend, scheduler, and frontend version metadata to `0.4.5` so runtime checks and build artifacts report the same release.

### Upgrade Notes

- No new database migration is included in this release. Deployments upgrading from v0.4.4 can reuse the existing schema.
- Rebuild backend, scheduler, and frontend artifacts together so API behavior, background-task processing, pricing data, and version metadata stay aligned.
- Review any custom upstream, pricing, or reverse-proxy configuration after upgrade, especially if you rely on relay timeout, retry, or billing edge-case behavior.
